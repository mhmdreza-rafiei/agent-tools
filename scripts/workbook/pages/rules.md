# Rules

Keep this page next to the work.

1. Missing facts that would lock the project: ask. Do not invent.
2. No git writes until you say so.
3. Small diffs you can read in one sitting.
4. “Done” means the checklist commands actually ran.
5. Do not improve files you did not name.
6. You merge. A review bot is extra, not a replacement.

Research sessions: zero file and git side effects until you switch tracks.
