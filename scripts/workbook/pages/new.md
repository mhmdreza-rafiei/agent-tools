# New project

Use when the repo does not exist yet.

1. Write project identity: who it is for, the problem, the first slice.
2. Write what is out of scope for slice one.
3. Write how you will know slice one worked (a command, URL, or demo).
4. Fill **checklist.pdf**.
5. Create git before any scaffold. Confirm this first.
6. Standing file: how to install, run, and test.
7. Build only the first slice. Prove it. Then the next.

Do not add Docker, CI, extra features, or a second framework on day one unless the spec requires them.
