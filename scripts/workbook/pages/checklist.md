# Checklist

Fill this before any AI session that will change a project. Research-only: still fill 1 and 2.

1. Outcome — one sentence, who it is for.
2. Must not — what the AI is forbidden to “improve.”
3. Stack — only if it is already chosen. Otherwise leave blank and decide later.
4. Read first — the 3–10 files that matter. Not the whole repo.
5. Where code lives — production, tests, generated folders to skip.
6. Success — exact commands you will run. If you cannot name a command, the work is still vague.
7. Git — repo exists? This session: commit / push / both / neither.

If a line is empty, stop. Fill it, then start.
