# onboard

Walk a new contributor through the repo layout, conventions, and their first PR.
Prints an onboarding guide built from the live tree (AGENTS.md, README.md, the
catalog counts). Pairs with the `codebase-onboarder` agent.

No external deps; Node built-ins only.

## Usage

```bash
node scripts/onboard/run.mjs
```
