# Start

Every session. Humans use `start.pdf`. You follow this file after they have picked a track.

1. Require a one-sentence outcome. If missing, ask. Do not start generating.
2. Require a filled checklist (`checklist.md` shape). Blank must-not, checks, or git permission → ask.
3. Stay on one track: `workflow/new.md`, `workflow/inherited.md`, or `workflow/research.md`.
4. Read `rules.md` plus that workflow file.
5. After work: ran checks, no invented facts, git only if permitted.

Point the human at `roadmap.md` if they want to skip to parallel agents from a blank repo.
