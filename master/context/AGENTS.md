# Master — for the AI

Default operating pack for any person or team. Not a per-user fork. Humans read the PDFs in the parent folder. You read this directory.

## Start

1. Read `rules.md`.
2. Read the workflow file the human named: `workflow/new.md`, `workflow/inherited.md`, or `workflow/research.md`.
3. Treat their filled checklist as the contract. Blank lines are blockers.
4. Do not invent product facts, metrics, stack, or biography.
5. Run the success commands before claiming done. Do not commit or push unless they said so.

## Layout

| Human (parent folder) | You (this folder) |
|-----------------------|-------------------|
| `start.pdf` | `start.md` |
| `checklist.pdf` | `checklist.md` |
| `roadmap.pdf` | `roadmap.md` |
| `new.pdf` | `workflow/new.md` |
| `inherited.pdf` | `workflow/inherited.md` |
| `research.pdf` | `workflow/research.md` |
| `rules.pdf` | `rules.md` |
| — | `practices.md`, `sources.md` (evidence; not for printing) |

## Do not

- Do not build a custom Master in someone else's home folder.
- Do not dump these files into a PDF.
- Do not add agentry markers (`SKILL.md`, `.mdc`) here unless asked to turn a piece into a catalog artifact.
